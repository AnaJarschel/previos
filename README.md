# PREVIOS
Sistema de Gestão de Saúde e Segurança do Trabalho (SST)

## Sobre o projeto
O **PREVIOS** é um sistema de gestão desenvolvido para auxiliar empresas que prestam serviços de **Saúde e Segurança do Trabalho (SST)**.

O projeto surgiu a partir da identificação de uma necessidade real: diversos processos realizados durante o atendimento às empresas são atualmente organizados por meio de **planilhas, documentos Word, arquivos e registros separados**, dificultando o controle e a consulta das informações.

A proposta do PREVIOS é centralizar essas informações em um único sistema, permitindo uma gestão mais organizada dos clientes, funcionários, visitas técnicas, levantamentos, documentos e prazos.
